# Security

This is a **public showcase repository**.

It intentionally does **not** contain the PraxisLock engine source code, production credentials, private keys, deployment secrets, or internal customer data.

## Reporting a security issue

If you identify a security issue in the public materials or want to privately discuss a security concern relating to PraxisLock, please use GitHub's private contact options for the repository owner.

Do not post sensitive vulnerability details in a public GitHub Issue.

## Current status

PraxisLock is an early-stage security prototype and is not represented as independently certified or production-ready.
